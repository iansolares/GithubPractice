1. ¿Qué es CSS?

CSS (Cascading Style Sheets) describe cómo se ven los elementos HTML: color, tamaño, forma, posición. Se llama "en cascada" porque los estilos se resuelven en capas cuando hay conflictos entre reglas.

Sintaxis básica:

selector {
  propiedad: valor;
}

3 formas de incluir CSS

  • Inline: dentro del atributo style de un elemento. Mala práctica — no se comparte entre elementos.
  • Interno: con una etiqueta <style> en el <head>. No se comparte entre documentos distintos.
  • Externo: en un archivo .css aparte, enlazado con <link>. La mejor práctica — se reutiliza en todo el sitio.
<link rel="stylesheet" href="estilos.css">

2. Colores y propiedades de texto

TAREA

Tipografía global (font-family)

font-family acepta una lista de opciones (font stack): el navegador usa la primera que tenga disponible.

html {
  font-family: Arial, Helvetica, sans-serif;
}
TAREA

Propiedades de texto

  • text-align: alineación horizontal (left, center, right).
  • letter-spacing: espacio entre letras.
  • font-size: tamaño del texto (px es una unidad absoluta).
  • color: color del texto (no confundir con el fondo).
  • font-weight: grosor del texto — normal (400), bold (700), bolder (relativo al padre), o un número de 100 a 900.
h1 {
  text-align: center;
  letter-spacing: 3px;
  font-size: 40px;
  color: #1b5e20;
}
TAREA

Colores con transparencia

background-color pinta el fondo (distinto de color, que pinta el texto). rgba(r, g, b, a) y hsla(tono, saturación, luminosidad, a) agregan un cuarto valor, alfa, la transparencia (0 = invisible, 1 = opaco).

#seccion {
  background-color: rgba(46, 125, 50, 0.08);
}
TAREA

Herencia de font-weight

Muchas propiedades de texto se heredan: si un contenedor (ul, ol) define un font-weight, sus hijos (li) lo heredan a menos que ellos mismos definan otro.

ul { font-weight: normal; }
ol { font-weight: bold; }

3. Selectores

SelectorAplica a
h1Todos los elementos de ese tipo
.claseTodos los elementos con class="clase"
#idEl único elemento con ese id
A BTodo B dentro de A (descendiente, sin importar qué tan anidado)
TAREA

Selector descendiente

Un espacio entre dos selectores significa "dentro de". nav a selecciona solo los <a> que están dentro de un <nav>, no todos los enlaces de la página.

nav a {
  text-decoration: none;
  color: #2e7d32;
}

Nombres de clase e id descriptivos

Un buen nombre dice de qué es el elemento, no solo qué le pasa visualmente. .caja2 o .destacado no dicen nada del contenido; .tarjeta-producto u .oferta-destacada sí. Lo mismo con ids: #boton1 dice poco, #carrito-agregar dice a qué componente pertenece y qué hace.

TAREA

Selectores de atributo

Seleccionan elementos según un atributo HTML. [attr^="valor"] selecciona los que EMPIEZAN con ese valor (también existen $= termina con, y *= contiene).

a[href^="#detalle"] {
  color: darkred;
}

4. Combinadores

Los combinadores describen la relación entre dos selectores.

CombinadorSignifica
A > BB es HIJO DIRECTO de A (no nieto)
A ~ BB es cualquier hermano que aparezca DESPUÉS de A
A + BB es el hermano INMEDIATO siguiente de A
TAREA 
#seccion li > a {
  background-color: #c8e6c9;
}
#seccion span ~ a {
  background-color: #ffe0b2;
}
#seccion span + a {
  background-color: #ffccbc;
}

Ejemplo: en <li><span>Nuevo</span><br><a>...</a></li>, el <br> en medio hace que span ~ a sí aplique, pero span + a no (no son adyacentes).

5. Pseudo-clases y pseudo-elementos

Una pseudo-clase (:algo) selecciona un elemento según su estado, no según su HTML.

Pseudo-claseCuándo aplica
:hoverMientras el mouse está encima
:activeMientras se hace clic
:checkedCuando un checkbox/radio está marcado
:nth-of-type(n)El n-ésimo elemento de ese tipo dentro de su contenedor
TAREA 
#carrito-agregar:hover { background-color: #388e3c; }
#carrito-comprar:active { background-color: #d84315; }
button:nth-of-type(3) { background-color: #fff3e0; }
input[type="radio"]:checked { accent-color: #2e7d32; }

Pseudo-elementos

Un pseudo-elemento (::algo) no selecciona algo que ya existe: CREA un elemento virtual dentro del seleccionado. ::before lo inserta al inicio, ::after al final. Siempre necesitan la propiedad content (aunque sea vacío) para poder verse, y se pueden combinar con una pseudo-clase.

TAREA 
p:hover::before {
  content: "Oferta-->";
  color: white;
  background-color: #1b5e20;
}
p:hover::after {
  content: "<--Descuento";
  color: white;
  background-color: #1b5e20;
}

6. Cascada y especificidad

Cuando dos reglas le aplican al mismo elemento, gana la más específica: id > clase/atributo > tipo de elemento. Si empatan en especificidad, gana la que está escrita más abajo en el código (o la más "externa": inline > <style> > archivo externo) — salvo !important, que invierte el orden.

Algunos elementos (como los botones) no heredan color automáticamente; se puede forzar con color: inherit;.

Chrome muestra, al inspeccionar un elemento, el CSS tachado cuando una regla pierde contra otra más específica — muy útil para depurar.
