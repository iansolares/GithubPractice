Teoría: Box Model y Animaciones CSS

Cómo se arma una caja en CSS, y cómo hacer que las cosas se muevan.

Box Model Transiciones Transforms Keyframes Animation

1. El Box Model

Todo elemento HTML es una caja rectangular con 4 capas, de adentro hacia afuera:

margin
border
padding
content
  • content: el contenido real (texto, imagen...). Su tamaño lo controlan width/height.
  • padding: espacio interno, entre el contenido y el borde.
  • border: el borde — necesita 3 propiedades para verse: border-style (trazo), border-width (grosor), border-color (color).
  • margin: espacio externo, entre esta caja y las demás. También existe margin negativo (valores como -10px), que hace que una caja se "monte" sobre otra.

width, height

.recuadro {
  width: 250px;
  height: 90px;
}

width/height también aceptan unidades relativas: % (relativo al padre), vw/vh (relativo a la ventana del navegador).

padding, border-radius

border-radius redondea las esquinas. Con 50% en una caja cuadrada se vuelve un círculo perfecto. Con valores distintos por esquina (border-top-left-radius, etc.) se pueden hacer formas asimétricas. 

.recuadro {
  padding: 0.5rem;
  border-radius: 12px;
}

border-style, border-color, border-width

.recuadro {
  border-style: dotted;  /* solid, dashed, double... */
  border-color: purple;
  border-width: 3px;
}

margin

Separa una caja de las demás. A diferencia de padding, no forma parte del "fondo" de la caja — si le pones background-color, el margin nunca se pinta. 

.recuadro {
  margin: 1.5rem;
}

overflow

Valor Qué hace
visible El contenido se sale de la caja (default)
hidden Se recorta lo que no cabe
scroll Aparece una barra de desplazamiento siempre
auto Barra solo si hace falta

display

Valor Qué hace
block Ocupa toda la línea (default de div, section, p...)
inline No rompe línea, ignora width/height (default de span, a...)
inline-block No rompe línea, PERO sí respeta width/height
none Oculta el elemento por completo (no ocupa espacio, a diferencia de visibility:hidden)
flex / grid Sistemas de layout para acomodar varios hijos

box-sizing

content-box (default): el padding y el border se SUMAN al width declarado. border-box: quedan DENTRO del width — el ancho final es el que pusiste, sin sorpresas. Por eso border-box es la opción más usada en proyectos reales. 

.recuadro {
  box-sizing: border-box;
}

position

Valor Qué hace
static Default, sigue el flujo normal de la página
relative Se mueve respecto a su posición original (con top/left/etc.)
absolute Se saca del flujo, se ubica respecto a su padre posicionado más cercano
fixed Respecto a la ventana — no se mueve al hacer scroll
sticky Combina relative y fixed: sigue el flujo hasta cierto punto, luego se "pega"

2. Transiciones

Una transición anima el cambio entre dos estados de un elemento (por ejemplo, normal → :hover). 

.enlace {
  transition-property: color;
  transition-duration: 0.2s;
  transition-timing-function: ease;
}

Dos transition-duration en un mismo selector

Si transition-property lista varias propiedades separadas por coma, transition-duration puede listar un tiempo distinto para cada una, en el mismo orden. 

.enlace {
  transition-property: color, transform;
  transition-duration: 2s, 0.5s;
}

Dos transition-timing-function distintas

steps(n, end) hace la transición "a saltos" (como stop-motion) en vez de suave — muy distinto a ease-out, que empieza rápido y termina lento. 

.enlace {
  transition-timing-function: steps(3, end), ease-out;
}

Otras timing-functions listas para usar: linear (velocidad constante), ease-in (empieza lento), cubic-bezier(x1,y1,x2,y2) (curva 100% personalizada — pueden armar la suya en cubic-bezier.com).

3. Transforms

transform modifica visualmente un elemento sin afectar el layout de sus vecinos (a diferencia de cambiar width/margin, que sí los empuja).

Función Qué hace
rotate(deg) Gira el elemento sobre su centro
translate(x, y) Lo mueve sin afectar a los demás elementos
scale(n) Lo agranda (>1) o encoge (<1)
skewX(deg) / skewY(deg) Lo inclina, efecto "cursiva"
rotateY(deg) / rotateX(deg) Gira en 3D sobre el eje vertical/horizontal — una forma simétrica se ve "adelgazar"

Se pueden combinar varias en una sola declaración, separadas por espacio: 

.icono:hover {
  transform: scale(1.2) rotate(10deg);
}

Tip: girar una forma perfectamente simétrica con rotate() normal casi no se nota (se ve igual en cualquier ángulo). Con rotateY() o rotateX() sí se nota, porque simulan el giro en 3D.

4. Keyframes

@keyframes define los pasos intermedios de una animación, con un nombre que luego se usa en animation-name (o en el shorthand animation). El nombre lo inventas tú — no tiene que coincidir con nada.

Notación from/to

from equivale a 0% y to a 100% — más legible cuando solo hay un estado inicial y uno final. 

@keyframes mi-transicion {
  from { opacity: 0.2; }
  to   { opacity: 1; }
}

Porcentaje numérico

Cuando la animación pasa por varios estados intermedios, se usan porcentajes. El paso intermedio no tiene que ser justo la mitad — puede ir donde tú quieras. 

@keyframes mi-recorrido {
  0%   { transform: translateY(0); }
  70%  { transform: translateY(-15px); }
  100% { transform: translateY(0); }
}

5. Animation

Propiedad Qué hace
animation-name Qué @keyframes usar
animation-duration Cuánto dura un ciclo completo
animation-iteration-count Cuántas veces se repite (infinite = para siempre)
animation-delay Cuánto espera antes de arrancar
animation-direction En qué sentido se reproduce
animation-play-state running o paused

animation-direction: alternate

Con normal (default), al llegar al final la animación salta de golpe al inicio. Con alternate, se reproduce AL REVÉS — va y regresa suavemente, como un péndulo. 

.elemento-generico {
  animation: mi-recorrido 2.5s linear infinite;
  animation-direction: alternate;
}

animation-play-state al pasar el cursor

Se puede pausar una animación en cualquier estado (por ejemplo :hover o :active) sin necesidad de JavaScript. 

.elemento-generico:hover {
  animation-play-state: paused;
}

Truco extra: si necesitas que la pausa se quede fija con un CLIC (no solo mientras el mouse está encima), se puede lograr sin JavaScript con un <input type="checkbox"> oculto + un <label>, usando el selector :checked ~.
