Teoría: Flexbox, Media Queries y Custom Properties

Cómo acomodar elementos en fila o columna, cómo adaptar un sitio a distintas pantallas, y cómo evitar repetir valores en tu CSS.

1. Flexbox

display: flex convierte a un elemento en un contenedor flex — sus hijos directos ("flex items") dejan de seguir el flujo normal del documento y se acomodan según las reglas de Flexbox. 

.contenedor {
  display: flex;
}

Main axis y cross axis

Todo contenedor flex tiene 2 ejes: el main axis (eje principal) y el cross axis (eje cruzado, perpendicular al principal). flex-direction decide cuál es cuál:

flex-direction Main axis Cross axis
row (default) Horizontal, izquierda→derecha Vertical
row-reverse Horizontal, derecha→izquierda Vertical
column Vertical, arriba→abajo Horizontal
column-reverse Vertical, abajo→arriba Horizontal

Los valores "reverse" solo voltean el sentido del main axis — no intercambian cuál eje es cuál.

flex-wrap

Por default (nowrap), todos los items se aprietan en una sola línea, encogiéndose si hace falta. Con wrap, los que no caben pasan a una nueva línea — esa nueva línea se acomoda a lo largo del cross axis. 

.contenedor {
  display: flex;
  flex-wrap: wrap;
}

Alinear: justify-content, align-items, align-self, align-content

Propiedad Eje que usa Afecta a...
justify-content Main axis Todos los items
align-items Cross axis Todos los items (dentro de su línea)
align-self Cross axis Un solo item (sobrescribe a align-items)
align-content Cross axis Líneas completas (solo se nota si hay más de una línea) 
.contenedor {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

.item-especial {
  align-self: flex-end;
}

flex-basis, flex-grow, flex-shrink

  • flex-basis: el tamaño "ideal" que un item pide, antes de ajustes.
  • flex-shrink: qué tanto puede encoger un item si TODOS piden más espacio del que hay (0 = nunca encoge).
  • flex-grow: qué tanto puede crecer un item si SOBRA espacio (0 = nunca crece, el default).

Se pueden combinar en el shorthand flex: grow shrink basis; 

.tarjeta {
  flex: 1 1 200px;
}

2. Media Queries

Un media query aplica un bloque de CSS SOLO si se cumple una condición sobre el dispositivo — casi siempre el ancho de la ventana, pero también existen alto, orientación, y otros. 

@media (condición) {
  selector {
    propiedad: valor;
  }
}

Las condiciones más comunes

Condición Reacciona a...
min-width La pantalla es AL MENOS esta de ancho
max-width La pantalla es COMO MÁXIMO esta de ancho
min-height / max-height Lo mismo, pero con el alto de la ventana
orientation landscape (más ancha que alta) o portrait (al revés) — sin importar el tamaño exacto

Combinar condiciones con and

Para un rango específico (ni muy chico ni muy grande), se combinan dos condiciones: 

@media (min-width: 600px) and (max-width: 900px) {
  .menu {
    font-size: 1.1rem;
  }
}

Diseño "mobile-first"

El CSS base (sin ningún media query) es para la pantalla más chica. Los media query van agregando/cambiando cosas a medida que la pantalla crece — casi siempre con min-width. Es más fácil de mantener que empezar por escritorio y "romper" hacia abajo. 

/* Base: celular */
.menu {
  flex-direction: column;
}

/* Ya cabe horizontal */
@media (min-width: 600px) {
  .menu {
    flex-direction: row;
  }
}

Ojo con el ORDEN en el archivo: si dos media query aplican al mismo tiempo (por ejemplo min-width:400px y max-width:850px en una pantalla de 700px), gana el que está escrito más abajo — igual que cualquier otra regla de CSS.

3. Custom Properties (variables CSS)

Una custom property se declara con -- al inicio del nombre, normalmente dentro de :root (para que esté disponible en toda la página). Se usa en cualquier lugar con var(--nombre). 

:root {
  --color-principal: seagreen;
  --espaciado: 1rem;
}

.tarjeta {
  background-color: var(--color-principal);
  padding: var(--espaciado);
}

Reasignar el valor de una variable

El valor de una variable se puede REASIGNAR dentro de un selector más específico, o dentro de un media query — todo lo que use var(--nombre) ahí adentro (o después, en la cascada) usa el nuevo valor, sin tener que tocar cada regla una por una. 

@media (min-width: 900px) {
  :root {
    --espaciado: 2rem;
  }
}

Esto es especialmente útil en diseño responsivo: en vez de repetir la misma fórmula con un valor distinto en cada media query, escribes la fórmula UNA vez con una variable, y cada breakpoint solo cambia el número.

Importante: una variable NO se puede usar dentro de la condición de un @media — no existe @media (min-width: var(--algo)), eso todavía no es estándar en CSS. Lo que sí funciona es cambiar el valor de la variable adentro del bloque, como en el ejemplo de arriba.

Extra - Cursor

Cuando un elemento clickeable (como un botón con estilos personalizados) pierde su apariencia nativa, a veces también deja de sentirse "clickeable". cursor: pointer le avisa al usuario que ese elemento se puede presionar, aunque visualmente ya no se parezca al botón por default del navegador. Es un detalle pequeño, pero se nota cuando falta. 

.boton-personalizado {
  cursor: pointer;
}

4. CSS Grid (el otro sistema de layout)

Flexbox acomoda en una dimensión a la vez (fila O columna). Grid acomoda en dos dimensiones a la vez (filas Y columnas simultáneas) — mejor para diseños tipo cuadrícula real, como un dashboard o una galería con posiciones fijas.

Lo básico

.tablero {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, 140px);
  gap: 1rem;
}

repeat(3, 1fr) crea 3 columnas de ancho igual (fr = "fracción" del espacio disponible) sin necesidad de calc() ni flex-basis — Grid hace esa cuenta por ti.

Áreas con nombre

Una de las cosas que Flexbox no puede hacer: nombrar zonas del layout y acomodar elementos por nombre, no por orden. 

.pagina {
  display: grid;
  grid-template-areas:
    "cabecera cabecera"
    "menu     contenido"
    "pie      pie";
  grid-template-columns: 200px 1fr;
}

.menu { grid-area: menu; }
.contenido { grid-area: contenido; }

¿Cuándo uno u otro?

Situación Mejor opción
No sabes cuántos elementos habrá (una lista que crece) Flexbox
Quieres alinear cosas en una sola fila o columna Flexbox
Necesitas una estructura de página completa (header/sidebar/contenido/footer) Grid
Quieres que algo ocupe varias filas o columnas a la vez Grid

En la práctica, muchos sitios usan Grid para la estructura general de la página, y Flexbox para acomodar el contenido DENTRO de cada sección de esa estructura — no son opciones excluyentes.
