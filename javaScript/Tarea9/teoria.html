Teoría: Fundamentos de JavaScript

Ya conocen condicionales, ciclos y funciones de otro lenguaje. Aquí vemos cómo se escriben esas mismas ideas en JavaScript, y algunos comportamientos que son propios del lenguaje. Los ejemplos son genéricos — no son el código de tu tarea. Lo marcado como EXTRA no se califica, pero es bueno conocerlo.

0. Cómo agregar JavaScript a una página

El código JS se guarda en un archivo aparte con extensión .js y se enlaza desde el HTML con la etiqueta <script>. En este curso lo haremos en el <head> con el atributo defer: 

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi página</title>
  <link rel="stylesheet" href="estilos.css">
  <script src="script.js" defer></script>
</head>
<body>
  ...
</body>
</html>
  • src indica la ruta del archivo, igual que en href o en una imagen.
  • defer hace que el archivo se descargue mientras se lee el HTML, pero que se ejecute hasta que toda la página ya se cargó. Así el código puede encontrar cualquier elemento del <body>.
  • Si hay varios scripts con defer, se ejecutan en el orden en que aparecen.
Sin defer, el script en el <head> se ejecuta antes de que exista el <body>, y algo como document.querySelector("#mensaje") regresa null.
defer solo funciona con archivos externos (con src). La etiqueta <script> siempre lleva cierre, aunque esté vacía.

EXTRA Otras formas que verán en internet

Forma Comentario
<script src="script.js"></script> justo antes de </body> Forma antigua de evitar el problema de null. Funciona, pero el archivo empieza a descargarse más tarde.
<script> ...código... </script> dentro del HTML Útil para ejemplos cortos; en proyectos reales mezcla HTML con lógica.

Dónde ver el resultado

Todo lo que se imprime con console.log() aparece en la consola del navegador: presionen F12 y abran la pestaña Console. Ahí también aparecen los errores, con el archivo y la línea donde ocurrieron.

1. Declarar variables

JavaScript tiene tres formas de declarar una variable. En código nuevo casi no se usa var.

Palabra ¿Se puede reasignar? ¿Cuándo usarla?
let Sí Cuando el valor va a cambiar (contadores, acumuladores, resultados).
const No Cuando el valor no cambia después de declararlo. Es la opción por defecto.
var EXTRA Sí Forma antigua, con reglas de alcance más confusas. Evítenla. 
let intentos = 0;
intentos = intentos + 1; // ok, let permite reasignar

const maximoIntentos = 10;
maximoIntentos = 20; // Error: Assignment to constant variable.
Nota: const en un arreglo no significa que el arreglo no cambie de contenido — significa que esa variable siempre va a apuntar al mismo arreglo. Sí se puede hacer push, pop, etc. sobre un arreglo declarado con const.

Lo que no se puede con const es reasignar la variable completa, por ejemplo para dejarla como un arreglo nuevo vacío. Para eso hay que declararla con let:

let pendientes = ["tarea", "examen"];
pendientes = []; // ok: let permite reasignar

const invitados = ["Ana", "Luis"];
invitados.push("Carla"); // ok: se modifica el contenido
invitados = [];          // Error: Assignment to constant variable.

Alcance (scope)

let y const solo existen dentro del bloque { } donde se declararon (scope de bloque). var EXTRA ignora los bloques y solo respeta el alcance de la función, lo cual causa errores difíciles de detectar.

if (true) {
  let mensaje = "hola";
  console.log(mensaje); // "hola"
}
console.log(mensaje); // Error: mensaje is not defined

Sugerencia de nombrado: usen camelCase para variables y funciones (nombreUsuario, no nombre_usuario ni NombreUsuario) — es la convención estándar en JavaScript.

2. Tipos de datos y tipado dinámico

JavaScript tiene tipado dinámico: no se declara el tipo de la variable, y una misma variable puede guardar distintos tipos en distintos momentos.

  • string: texto, entre comillas simples, dobles o con backticks.
  • number: no distingue enteros de decimales, son el mismo tipo.
  • boolean: true / false.
  • undefined: una variable que existe pero no tiene valor asignado.
  • null: un valor "vacío" asignado a propósito.
let dato = "hola";   // string
dato = 5;            // ahora es number, y no da error
console.log(typeof dato); // "number"

Truthy y falsy

Cuando JS necesita un booleano (por ejemplo dentro de un if) y le das otra cosa, la convierte. Solo estos valores se comportan como false ("falsy"); todo lo demás se comporta como true ("truthy"): 

false, 0, "", null, undefined, NaN
let mensajes = [];
if (mensajes) {
  console.log("Esto SÍ se ejecuta, un arreglo vacío es truthy");
}
if (mensajes.length) {
  console.log("Esto NO se ejecuta, 0 es falsy");
}
Error común: confundir un arreglo vacío (truthy) con "no hay nada" — para eso hay que revisar .length, no el arreglo directamente.

EXTRA Conversión de tipos (coerción)

El operador + con un string concatena en vez de sumar. Es la fuente de errores de tipos más común en JS:

5 + 5;      // 10
"5" + 5;    // "55"  (convierte el número a texto)
"5" - 2;    // 3     (aquí sí convierte el texto a número, - no sirve para concatenar)
5 + "5" + 1; // "551" (se evalúa de izquierda a derecha)

3. Comparación: == vs ===

== compara el valor pero convierte tipos si hace falta. === compara valor y tipo, sin conversión. En JS casi siempre se usa ===.

"5" == 5;   // true  (convierte el string a número)
"5" === 5;  // false (distinto tipo)
5 === 5;    // true
null == undefined;  // true
null === undefined; // false
Regla práctica: usen === y !== siempre, salvo que tengan una razón específica para lo contrario.

Operadores lógicos

Operador Significado
&& Y — las dos condiciones deben ser verdaderas
|| O — al menos una condición debe ser verdadera
! Niega el valor booleano 
let edad = 20;
let tieneCredencial = true;

if (edad >= 18 && tieneCredencial) {
  console.log("Puede entrar");
}

if (edad < 12 || edad > 65) {
  console.log("Tarifa especial");
}

4. Template literals

Con backticks (`) se pueden insertar variables directo dentro de un texto usando ${'{'}variable{'}'}, en vez de concatenar con +.

let nombre = "Ana";
let edad = 23;

// Antes:
console.log("Hola " + nombre + ", tienes " + edad + " años");

// Con template literal:
console.log(`Hola ${nombre}, tienes ${edad} años`);

También se pueden meter operaciones y hasta llamadas a funciones dentro de ${'{'}...{'}'}:

console.log(`El doble de ${edad} es ${edad * 2}`);
console.log(`En mayúsculas: ${nombre.toUpperCase()}`);

EXTRA A diferencia de un string normal, un template literal puede abarcar varias líneas tal cual, sin usar \n:

let mensaje = `Línea uno
Línea dos`;

5. Condicionales

La lógica es la misma que ya conocen; esto es solo la sintaxis de JS.

let temperatura = 30;

if (temperatura > 35) {
  console.log("Hace mucho calor");
} else if (temperatura > 20) {
  console.log("Clima agradable");
} else {
  console.log("Hace frío");
}

switch es útil cuando comparas una misma variable contra varios valores posibles:

let dia = 3;

switch (dia) {
  case 1:
    console.log("Lunes");
    break;
  case 2:
    console.log("Martes");
    break;
  case 3:
    console.log("Miércoles");
    break;
  default:
    console.log("Otro día");
}
No olviden el break en cada case — si lo omiten, sigue ejecutando los casos de abajo aunque no hagan match ("fall-through").

EXTRA Operador ternario

Es una forma corta de escribir un if/else que solo asigna un valor:

let edad = 16;
let entrada = edad >= 18 ? "Adulto" : "Menor";

// Es equivalente a:
let entrada2;
if (edad >= 18) {
  entrada2 = "Adulto";
} else {
  entrada2 = "Menor";
}

6. Ciclos

Ciclo Cuándo usarlo
for Cuando sabes cuántas veces vas a repetir (típicamente recorriendo un índice).
while Cuando repites mientras se cumpla una condición, sin saber de antemano cuántas veces.
for...of Cuando quieres recorrer los valores de un arreglo directamente, sin manejar el índice. 
// for clásico
for (let i = 0; i < 5; i++) {
  console.log(i);
}

// while
let intentos = 0;
while (intentos < 3) {
  console.log("Intento " + intentos);
  intentos = intentos + 1;
}

// for...of sobre un arreglo
let colores = ["rojo", "verde", "azul"];
for (let color of colores) {
  console.log(color);
}

break y continue

for (let i = 0; i < 10; i++) {
  if (i === 5) break;     // termina el ciclo por completo
  if (i % 2 === 0) continue; // salta a la siguiente vuelta
  console.log(i); // imprime 1, 3
}

EXTRA do...while

Igual que while, pero revisa la condición al final, así que el cuerpo se ejecuta al menos una vez:

let numero;
do {
  numero = Math.floor(Math.random() * 10);
} while (numero !== 7);

7. Funciones

Hay dos formas comunes de escribir una función en JS:

// Declaración de función
function sumar(a, b) {
  return a + b;
}

// Función flecha (arrow function), guardada en una variable
const sumar2 = (a, b) => {
  return a + b;
};

sumar(2, 3);  // 5
sumar2(2, 3); // 5

Si el cuerpo de la función es una sola línea con return, la flecha se puede escribir aún más corta:

const sumar3 = (a, b) => a + b;
Una función que no tiene return explícito, regresa undefined. Eso es importante: si una función debe "regresar un resultado", necesita un return con ese valor.

Salir antes con return

return termina la función en ese momento; lo que está abajo ya no se ejecuta. Por eso conviene revisar primero los casos inválidos y salir de inmediato. A esto se le llama cláusula de guarda, y evita anidar el resto del código dentro de un else:

// Con else: el caso normal queda anidado
function dividir(a, b) {
  if (b !== 0) {
    return a / b;
  } else {
    return null;
  }
}

// Con cláusula de guarda: el caso inválido sale primero
function dividir2(a, b) {
  if (b === 0) {
    return null; // se sale aquí, lo de abajo ya no corre
  }
  return a / b;
}

Una función también puede regresar un booleano para avisar si pudo hacer su trabajo:

function esMayorDeEdad(edad) {
  if (edad < 18) {
    return false;
  }
  return true;
}

if (!esMayorDeEdad(15)) {
  console.log("No puede votar");
}

Parámetros y valores por defecto

function saludar(nombre = "invitado") {
  return `Hola, ${nombre}`;
}

saludar("Luis"); // "Hola, Luis"
saludar();       // "Hola, invitado"

Funciones que llaman a otras funciones

Una función puede usar el resultado de otra — es normal dividir un problema en varias funciones pequeñas en vez de escribir todo en una sola:

function calcularSubtotal(precio, cantidad) {
  return precio * cantidad;
}

function calcularConImpuesto(precio, cantidad) {
  const subtotal = calcularSubtotal(precio, cantidad);
  return subtotal * 1.16;
}

8. Arrays (arreglos)

let frutas = ["manzana", "pera", "uva"];

frutas.length;      // 3
frutas[0];           // "manzana"
frutas[frutas.length - 1]; // "uva" (el último elemento)

frutas.push("mango"); // agrega al final
frutas;                // ["manzana", "pera", "uva", "mango"]

Modificar un elemento por su índice

Con los corchetes no solo se lee un elemento, también se le puede asignar un valor nuevo:

let vidas = [3, 3, 3];

vidas[1] = 5;            // [3, 5, 3]
vidas[0] = vidas[0] - 1; // [2, 5, 3]  (usa su propio valor para calcular el nuevo)

EXTRA Otros métodos para agregar/quitar

Método Qué hace
push(valor) Agrega al final
pop() Quita y regresa el último elemento
unshift(valor) Agrega al inicio
shift() Quita y regresa el primer elemento

Recorrer un arreglo con índice (útil cuando necesitas el índice, por ejemplo para comparar dos arreglos en paralelo):

let temperaturas = [22, 25, 19, 30];

for (let i = 0; i < temperaturas.length; i++) {
  console.log(`Día ${i}: ${temperaturas[i]}°C`);
}

Acumular un resultado

Para obtener un solo valor a partir de todo el arreglo (una suma, un conteo), se declara una variable antes del ciclo y se va actualizando en cada vuelta:

let calificaciones = [8, 9, 7, 10];
let aprobados = 0; // empieza en 0

for (let i = 0; i < calificaciones.length; i++) {
  if (calificaciones[i] >= 8) {
    aprobados = aprobados + 1;
  }
}

console.log(aprobados); // 3
Si el arreglo está vacío, el ciclo no da ninguna vuelta y la variable se queda con su valor inicial. Por eso importa elegir bien ese valor.

Buscar dentro de un arreglo

Se recorre comparando elemento por elemento. En cuanto se encuentra lo buscado, el return termina la función, y con ella el ciclo. Si el ciclo termina sin encontrarlo, se regresa un valor que indique "no hay", como -1:

// Regresa la posición del primer número mayor que el límite
function buscarPrimeroMayor(numeros, limite) {
  for (let i = 0; i < numeros.length; i++) {
    if (numeros[i] > limite) {
      return i;
    }
  }
  return -1; // ninguno fue mayor
}

buscarPrimeroMayor([4, 9, 12], 8);  // 1
buscarPrimeroMayor([4, 9, 12], 20); // -1
EXTRA Los arreglos también tienen métodos que hacen esta búsqueda por ustedes, como indexOf() o includes() — MDN — indexOf. No es obligatorio usarlos, un for normal funciona igual de bien.

EXTRA forEach

Otra forma de recorrer un arreglo, ejecutando una función por cada elemento:

let colores = ["rojo", "verde", "azul"];
colores.forEach(function (color, indice) {
  console.log(`${indice}: ${color}`);
});

Arreglos en paralelo

Una forma común de guardar datos relacionados sin usar objetos (los objetos los vemos en otra clase) es usar varios arreglos donde la misma posición representa al mismo elemento:

let alumnos = ["Ana", "Luis", "Carla"];
let edades = [21, 23, 20];

// La persona en la posición 1 de ambos arreglos es la misma:
console.log(`${alumnos[1]} tiene ${edades[1]} años`);

9. Una probadita del DOM EXTRA

Todavía no vemos DOM a fondo (eso viene en una clase dedicada), pero con lo que ya saben pueden hacer que un botón dispare una función de JS. Eso se hace con el atributo onclick en el HTML:

<!-- index.html -->
<button onclick="saludar()">Saludar</button>
<p id="mensaje"></p>
// script.js
function saludar() {
  document.querySelector("#mensaje").textContent = "¡Hola!";
}
  • document.querySelector("#mensaje") busca en la página el primer elemento que coincida con ese selector. Usa los mismos selectores que CSS: #id, .clase, etiqueta.
  • .textContent cambia el texto que se muestra dentro de ese elemento.

También se le puede pasar un valor a la función que llama el botón:

<!-- index.html -->
<button onclick="votar(3)">Votar por la opción 3</button>
// script.js
function votar(opcion) {
  console.log(`Votaste por la opción ${opcion}`);
}
