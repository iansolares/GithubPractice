Semántica Div/Span Formularios Tablas Extras

1. Elementos semánticos

Antes de HTML5, casi todo se armaba con <div>. Los elementos semánticos son "divs con nombre": describen qué tipo de contenido hay dentro. De hecho, esta misma página los está usando: todo el documento está dentro de un <header>, un <main> con varios <section>, y termina en un <footer>.

  • <header>: encabezado de la página o de una sección.
  • <nav>: bloque de enlaces de navegación.
  • <main>: el contenido principal y único de la página.
  • <section>: una sección temática dentro del documento.
  • <article>: contenido independiente y autocontenible.
  • <aside>: contenido relacionado pero secundario.
  • <footer>: pie de página.

¿Por qué usarlos en vez de <div> para todo? Accesibilidad (un lector de pantalla puede saltar directo al contenido principal), SEO (los buscadores entienden mejor la estructura), y mantenimiento (el código es más fácil de leer).

2. Elementos de bloque e inline

  • <div>: contenedor genérico de bloque (ocupa toda la línea). Se usa para agrupar y luego darle estilo con CSS.
  • <span>: contenedor genérico inline (no rompe la línea). Se usa para marcar una palabra o frase suelta dentro de un párrafo.

Ninguno de los dos tiene significado propio; son "cajas" neutras.

3. Formularios

  • <form>: contenedor del formulario. action indica a dónde se envían los datos; method indica cómo (get los pone en la URL, post los manda ocultos).
  • <fieldset> + <legend>: agrupan un conjunto de campos relacionados, con un título.
  • <label for="...">: se asocia programáticamente con el campo cuyo id coincide. Un lector de pantalla lo lee al enfocar el campo, y al hacer clic en el label también se activa el input. 
<form action="/enviar" method="post">
  <fieldset>
    <legend>Datos de contacto</legend>
    <label for="mail">Correo:</label>
    <input type="email" id="mail" name="mail" placeholder="tu@correo.com">
  </fieldset>
</form>

Tipos de input más comunes

Tipo Uso
text texto libre de una línea
email valida formato de correo
password oculta el texto con puntos/asteriscos
number solo acepta números
radio una opción entre varias excluyentes (mismo name)
checkbox una o varias opciones no excluyentes
range selector deslizable entre un mínimo y máximo
color selector de color
file subir un archivo

Otros campos

<textarea>: texto largo (varias líneas).

<textarea name="comentario" cols="40" rows="6"></textarea>

<select> + <option>: menú desplegable. 

<select name="pais">
  <option value="mx">México</option>
  <option value="es">España</option>
</select>

Botones

  • <button type="submit">: envía el formulario.
  • <button type="button">: no hace nada por sí solo — se usa con JavaScript.

El atributo name

id identifica un elemento en la página (para CSS/JS/labels). name es lo que se envía al servidor. Un input sin name no se envía.

Accesibilidad y errores comunes

  • Todo input debería tener su <label> correctamente asociado (for = id).
  • Olvidar name hace que el dato no se envíe.

4. Tablas

Una tabla sirve para mostrar datos tabulares (filas y columnas relacionadas). No debe usarse para acomodar el diseño de una página completa.

  • <table>: contenedor de toda la tabla.
  • <tr>: una fila (table row).
  • <th>: celda de encabezado (negritas por defecto).
  • <td>: celda de datos normal.
  • <thead> / <tbody>: agrupan encabezado y cuerpo — ayuda a lectores de pantalla y a quien lea el código después.

colspan une celdas horizontalmente. rowspan une celdas verticalmente. Ambos deben ser mayores a 1 — usarlos con valor 1 es lo mismo que no ponerlos y no cuenta. 

<table>
  <thead>
    <tr>
      <th rowspan="2">País</th>
      <th colspan="2">Población</th>
    </tr>
    <tr>
      <th>Urbana</th>
      <th>Rural</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>México</td>
      <td>80%</td>
      <td>20%</td>
    </tr>
  </tbody>
</table>

Así se ve renderizado:

País Población
Urbana Rural
México 80% 20%

"País" ocupa dos filas (no se repite abajo) y "Población" ocupa dos columnas.

5. Extras (no se califican en la tarea)

Estos elementos no forman parte de lo que se revisa en la tarea, pero se muestran en clase como ejemplo y vale la pena conocerlos.

EXTRA

hr y br

  • <hr>: thematic break — línea horizontal que indica cambio de tema.
  • <br>: salto de línea simple dentro de un mismo bloque de texto. 
<p>
  Primera línea<br>
  Segunda línea
</p>
<hr>
<p>Nuevo tema</p>
EXTRA

sup y sub

  • <sup>: superíndice (texto elevado), típico en exponentes o notas.
  • <sub>: subíndice (texto bajado), típico en fórmulas químicas.

El agua es H2O  ·  Área = lado2

<p>El agua es H<sub>2</sub>O</p>
<p>Área = lado<sup>2</sup></p>
EXTRA

Entidades HTML

Una entidad representa un carácter que el navegador podría confundir con código, o que no está en el teclado. Empieza con &, sigue un código, y termina en ;.

Carácter Entidad Código numérico
< &lt; &#60;
> &gt; &#62;
& &amp; &#38;
© &copy; &#169;
espacio irrompible &nbsp; &#160;

Cuando se pide "usar la entidad", se refiere al código (&copy;), no al símbolo ya escrito (©) — en el código fuente no es lo mismo aunque se vean igual en el navegador.

Más códigos: entitycode.com · especificación oficial

EXTRA

Columna de imágenes en una tabla

Se puede meter un <img> dentro de un <td> como cualquier otro contenido: 

<td><img src="https://ejemplo.com/foto.png" width="64" height="64" alt="Descripción"></td>

width/height fijan el tamaño de la imagen, y alt describe qué se ve (accesibilidad).
